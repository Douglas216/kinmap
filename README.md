KinMap is a very simple tool to record relationships of one's extended family members. It is motivated by the urge that I want to know exactly how I'm related to each of them. 

In contrary to traditional heritage trees, I not only want to record the paternal side of the family, but also family connected by marriage. This is achieved by grouping a married couple as a union node with a double-sided arrow in the middle, which acts as a toggle to reveal the family tree on the paternal and maternal side. Only one side of the union node can be active at a time. 

By clicking on the name of each individual, a panel that shows basic information of this person is revealed, where info such as location, DOB, alive/death status can be seen.
